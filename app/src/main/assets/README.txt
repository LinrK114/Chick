自定义资源说明：

1. 中间小图片：
   把图片放到本目录，文件名可以是：
   - center_image.png
   - center_image.jpg
   - center_image.jpeg
   - center_image.webp
   推荐 PNG，建议正方形，建议尺寸 512x512 或 1024x1024。

2. 点击音效：
   把音频放到本目录，文件名可以是：
   - click_sound.mp3
   - click_sound.ogg
   - click_sound.wav
   推荐 MP3 或 OGG，时长建议 0.5~2 秒。

如果没有这些文件，应用仍然可以编译运行：
- 中间图片会使用默认的绿色圆形
- 点击时只有缩放动画，没有声音
